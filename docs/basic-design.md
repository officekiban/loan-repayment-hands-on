# 返済シミュレータ 基本設計書

- 文書版: v0.3
- 対象: ダミー条件を使うハンズオン用モック
- 非対象: 実際の融資条件、審査、契約、返済額の確定

## 1. 入力

| ID | 項目 | 単位 | 条件 |
|---|---|---|---|
| IN-01 | 借入金額 | 円 | 1円以上の整数。画面では3桁区切りのコンマを表示する |
| IN-02 | 年利 | % | 0%以上100%以下 |
| IN-03 | 返済年数 | 年 | 1年以上100年以下の整数 |
| IN-04 | 元金据置期間 | か月 | 0以上、総返済月数未満の整数 |
| IN-05 | 返済方式 | - | 元利均等または元金均等 |

## 2. 共通処理

- 毎月払いとする。
- ボーナス返済、手数料、遅延損害金および繰上返済は扱わない。
- 月利は `年利 ÷ 12 ÷ 100` とする。
- 元金据置期間中は元金を減らさず、毎月の利息だけを支払う。
- 元金の返済回数は `返済年数 × 12 − 元金据置月数` とする。

## 3. 返済方式

### BD-METHOD-01 元利均等

元金返済開始後の毎月返済額を一定とする。利息が減るにつれて、毎月返済額に占める元金部分が増える。

### BD-METHOD-02 元金均等

元金返済開始後の毎月の元金部分を一定とする。利息は返済前残高に応じて減るため、毎月返済額も徐々に減る。

## 4. 出力

| ID | 項目 | 内容 |
|---|---|---|
| OUT-01 | 返済開始月の返済額 | 元金返済を開始する月の元金と利息の合計 |
| OUT-02 | 最終回返済額 | 最終月の元金と利息の合計 |
| OUT-03 | 据置期間中の月額 | 据置期間がある場合の毎月利息 |
| OUT-04 | 総返済額 | 全期間の元金と利息の合計 |
| OUT-05 | 利息総額 | 全期間の利息の合計 |
| OUT-06 | 返済予定表 | 各月の区分、返済前残高、元金、利息、返済額および返済後残高 |

### BD-OUT-01 返済予定表

- 総返済月数と同じ件数の行を作成し、1回目から最終回までを月順に表示する。
- 元金据置期間の行は区分を`据置`とし、元金を0円、返済後残高を返済前残高と同額にする。
- 元金返済開始後の行は区分を`返済`とし、選択した返済方式に従って元金と利息を表示する。
- 最終行の返済後残高は0円とし、全行の元金合計を借入金額と一致させる。
- 画面では12件ずつ表示し、最初、前、次および最後のページへ移動できるようにする。
- 返済予定表の各金額も、本書5章の端数処理の対象とする。端数規則が確定するまで、画面上の値は概算として扱う。

## 5. 端数処理

### BD-RND-01 毎月利息

各月の利息は、返済前残高に月利を乗じた後、1円未満を切り捨てる。切捨て後の利息を当月返済額および総返済額へ加算する。

### BD-RND-02 元金の端数

各月の元金返済額は1円単位とし、通常月の計算で生じる1円未満の端数は最終月に調整する。最終月の元金返済額は、その時点の残元金全額とする。返済方式にかかわらず、全期間の元金返済額の合計を借入金額と一致させる。端数調整により、最終月の返済額が通常月の返済額と異なる場合がある。

## 6. 人間確認点

本書はハンズオン用の設計案である。実装前に、要件、テスト仕様および業務上の端数処理との整合を人が確認し、採用、修正または保留を決める。
