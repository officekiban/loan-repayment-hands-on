# 返済シミュレータ テスト仕様書

- 文書版: v0.3
- 対象: 返済シミュレータの計算・表示確認
- 使用情報: ダミー値のみ

## テストケース

| ID | 確認対象 | 入力・操作 | 期待結果 |
|---|---|---|---|
| TS-01 | 金額表示 | 借入金額に`3000000`を入力する | 入力欄に`3,000,000`と表示される |
| TS-02 | 元利均等 | 借入金額300万円、年利1.5%、10年、据置0か月、元利均等で計算する | 返済開始月と最終回の返済額が同額になる |
| TS-03 | 元金均等 | TS-02と同じ条件で元金均等を選ぶ | 返済開始月の返済額が最終回返済額より大きくなる |
| TS-04 | 据置 | 借入金額300万円、年利1.5%、10年、据置6か月で計算する | 6か月は利息のみを払い、その後114回で元金を返済する |
| TS-05 | 利息端数 | 借入金額100,500円、年利1.2%として初月利息を計算する | `100,500 × 1.2% ÷ 12 = 100.5`を四捨五入し、101円とする |
| TS-06 | 据置上限 | 返済年数1年、据置12か月で計算する | 元金返済期間がないため入力エラーとする |
| TS-07 | 金利0% | 年利0%で計算する | 利息総額が0円となり、元金だけを返済回数で分割する |
| TS-08 | 返済予定表 | 借入金額120,000円、年利0%、1年、据置0か月、元利均等で計算する | 12行を表示し、各月の元金と返済額が10,000円、利息が0円、最終行の返済後残高が0円となる |
| TS-09 | 予定表ページ送り | 借入金額300万円、年利1.5%、10年、据置0か月で計算する | 全120回を12件ずつ10ページで表示し、最初、前、次および最後のページへ移動できる |
| TS-10 | 据置行 | 返済年数1年、据置6か月で計算する | 1〜6回を`据置`、7〜12回を`返済`と表示し、据置行の元金が0円で残高が変わらない |

## 合否記録

各テストについて、実測値、合否、差異、確認者および確認日を記録する。仕様間に矛盾がある場合は、実装またはテストの一方をAIが独断で正とせず、人間判断へ引き継ぐ。
